# 킴투의 전설

## 프로젝트 개요
- **장르**: 액션 어드벤처 RPG
- **플랫폼**: PC
- **시점**: 3인칭 숄더뷰
- **엔진**: Unity 6.04
- **제작 기간**: 3주
- **참고 작품**: 원신, 젤다
- **타겟 유저**: 12세 이상
- **시연 영상 링크**: [YouTube – 킴투의 전설 시연 동영상](https://www.youtube.com/watch?v=Oy2EASIdb8w) 
## 스토리
### 로그라인
> 쿠쿠대왕에게 납치된 남매! 주인공은 하나뿐인 가족을 구하기 위해, 위험천만하지만 흥미진진한 모험이 펼쳐지는 ‘쿠쿠섬’으로 뛰어든다.  

### 시놉시스
> 김투 남매(김투와 김원)는 별나라를 여행하던 중 ‘쿠쿠섬’에 도착한다.  
> 하지만 동생 김원이 쿠쿠대왕에게 납치되고, 의식을 잃었던 김투는 낯선 언덕 위에서 깨어난다.  
> 잃어버린 동생을 구하기 위한 모험이 시작된다.  

## 핵심 키 포인트
1. 모험 → 좌절 → 극복  
2. 맵 자유도 및 난이도 조절  
3. 성취감 부여
